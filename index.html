What is built and running

No model reaches phones without the gate and a named person

PROMOTEBetter, and no worse for any vehicle or speed. A person approves; it ships to app and server.
REJECTWorse somewhere that matters, or the model file is broken.
INCONCLUSIVEToo little evidence. Shipping needs a person's explicit sign-off.
OPERATING POINTOnly a setting changed. The gate shows the trade-off; a person decides.
